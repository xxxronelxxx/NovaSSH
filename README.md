SSH/SFTP-коммандер для Windows и Android: две панели, архивы как папки, группы серверов,
полностью настраиваемая внешность.

- Ядро: Rust (`rust/core`) — SFTP (russh), крипто (Argon2id + AES-256-GCM), JSON-хранилище.
- UI: Flutter (`app`) — Windows + Android, Mica/полупрозрачность на Windows.
- Мост: flutter_rust_bridge 2.13 (типы модели генерируются в обычные Dart-классы).
- Идентификаторы: `ru.devspb.nova`, приложение `NovaSSH`, DLL/so: `nova_core`.

## Быстрый старт

```powershell
# 1. Один раз: доустановить C++ CMake tools в VS2022 (нужен UAC, только для Windows-сборки)
powershell -ExecutionPolicy Bypass -File tools\install-prereqs.ps1

# 2. Ядро
cargo test -p nova_core

# 3. Генерация моста после правок в rust/core/src/api.rs или model.rs
flutter_rust_bridge_codegen generate

# 4. Windows: portable ZIP и установщик
powershell -ExecutionPolicy Bypass -File tools\package-windows.ps1
powershell -ExecutionPolicy Bypass -File tools\package-windows-installer.ps1
# → dist\NovaSSH-<версия>-windows-x64-portable.zip
# → dist\NovaSSH-<версия>-windows-x64-installer.exe

# debug-цикл во время разработки
cd app; flutter run -d windows

# 5. Android (Rust-ядро для нужных ABI собирает Gradle)
powershell -ExecutionPolicy Bypass -File tools\package-android.ps1 -Universal
# → dist\android\NovaSSH-<версия>-universal.apk (arm64-v8a + armeabi-v7a + x86_64)

# arm64-only APK поменьше:
powershell -ExecutionPolicy Bypass -File tools\package-android.ps1

# обновить статические бейджи (размер установщика) после нового релиза
cd tools\badges; npm install; npm run update
```

> Релизные APK подписываются ключом `keys\novassh-release.jks`
> (`app/android/key.properties`, в git не попадают). Без этих файлов сборка
> откатывается на debug-подпись и не подойдёт для обновления установленного
> релиза. Ключ и пароли нужно хранить в надёжном месте.

## Встроенный редактор, сессии, журнал

- **F4** открывает встроенный редактор с подсветкой (php/js/json/html/css/sql/ini/sh/py/dart/rs/md/yaml),
  если внешний не задан; в настройках есть кнопка «Встроенный», чтобы переключиться.
  Ctrl+S сохраняет, локально или на сервер, закрытие с правками спрашивает подтверждение.
- **Восстановление сессий**: список открытых серверов и путей пишется в `state.json`;
  на экране серверов появляется «Прошлая сессия … Продолжить», вкладки открываются тихо
  (без окон прогресса и ошибок для недоступных серверов).
- **Журнал событий**: Настройки → О программе → «Журнал событий»; хвост `nova.log`,
  фильтр «только ошибки», копирование, открытие папки.
- **Drag & drop** из/в Проводник: файлы и папки, брошенные на панель, копируются
  (локальная) или загружаются (серверная).
- **Стрелки**: ↑/↓ — по списку, ← — на строку «..» (в начало), → — в конец
  списка, Enter — войти в папку или открыть файл, Backspace — вверх, Tab — другая
  панель.
- **Фильтр по имени** (Ctrl+F) сужает список активной панели по подстроке;
  `Esc` очищает и возвращает клавиатуру панели. При вводе фильтра подгружаются
  скрытые файлы, поэтому `.env` или `.config` находятся без включения «показывать
  скрытые». Быстрый поиск по первой букве работает, когда фокус на панели.
- **Сохранение из внешнего редактора**: Ctrl+S можно нажимать сколько угодно раз,
  не закрывая файл — каждая правка загружается на сервер (раньше работала только
  первая).
- **Временные копии**: отредактированный файл лежит в `tmp/<сервер>/…`; при
  закрытии последней вкладки этого сервера папка удаляется, а при запуске
  программы `tmp` очищается целиком. Архивы открываются на чтение напрямую и в
  `tmp` не копируются.
- **Журнал редактирования**: Настройки → «Редактор и терминал» → «Записывать
  логи в папку logs». При включении каждое открытие и сохранение файла пишется
  в `logs/<сервер>_ДД-ММ-ГГГГ.log` с датой, временем, сервером и путём; у
  каждого сервера и дня свой файл. Просмотр и выбор файла — в «Журнале событий».
- **Передачи**: докачка с места обрыва, пауза с сохранением частичного файла,
  лимит скорости и необязательная проверка SHA-256 после копирования.

## Архивы

Архив открывается двойным щелчком и ведёт себя как папка: вход внутрь,
`Backspace` — на уровень выше, `F3` — просмотр, `Ctrl+F3` — сравнение с файлом
из другой панели, `F5` — копирование из архива в любую панель (в том числе на
сервер).

- **Чтение**: ZIP, TAR, TAR.GZ/TGZ, TAR.BZ2, TAR.XZ, TAR.ZST, 7Z, а также
  одиночные GZ/BZ2/XZ/ZST (показываются одним файлом; GZ отдаёт исходное имя).
- **Создание**: контекстное меню → «Создать архив…», формат выбирается в
  диалоге. Работает и в локальной панели, и в панели сервера — там архив
  собирают `tar`/`zip`/`7z` прямо на сервере, файлы не гоняются по сети.
- **Распаковка**: `Ctrl+F5` в соседнюю панель. Если обе панели на сервере,
  распаковка идёт на сервере (`tar -xf`, `unzip`, `7z x`); если архив на
  сервере, а панель локальная — архив один раз скачивается во временную папку
  и распаковывается локально.
- **Добавление в архив**: откройте архив в одной панели, выделите файлы в
  другой и нажмите `F5`. Архив пересобирается целиком (сжатые TAR и 7Z нельзя
  дописать на месте), поэтому для очень больших архивов операция не мгновенная.
- **Индекс**: список файлов архива копится в `cache/idx` рядом с профилем и
  переиспользуется, пока не изменились размер и время файла — открытие большого
  архива не перечитывает его целиком.
- **Безопасность**: имена внутри архива недоверенные; `../../x` и абсолютные
  пути при распаковке отбрасываются, наружу ничего не пишется.

## Сниппеты и ИИ-помощник

- **Сниппеты** — сохранённые команды в `snippets.json` внутри профиля. В терминале над
  строкой ввода видна лента избранного; кнопка «⚡» открывает список с поиском
  (`Ctrl+Shift+P` на Windows), «＋» сохраняет текущую строку, а выделенный вывод можно
  сохранить через контекстное меню. По умолчанию команда только вставляется; «выполнять
  сразу» включается для отдельного сниппета и спрашивает подтверждение. Подстановки:
  `{path}`, `{file}`, `{host}`, `{user}`, `{port}`, `{server}`, `{prompt:Вопрос}`.
- **ИИ** — Настройки → ИИ: OpenCode Zen, OpenCode Go, OpenRouter или свой
  OpenAI-совместимый endpoint. Ключ хранится в зашифрованном хранилище, список моделей
  берётся у провайдера через `/models` (ничего не захардкожено). Помощник вызывается
  кнопкой ✨ в терминале и в редакторе сниппетов, отвечает **одной командой** и сам
  ничего не выполняет: «Вставить», «Выполнить» (с подтверждением) или «Сохранить как
  сниппет». Запрос уходит напрямую с устройства на выбранный endpoint.



Одно и то же приложение, но на узком экране панели показываются по одной:

- сверху переключатель «Локально / сервер», панели листаются свайпом
  влево-вправо (как в Total Commander на Android);
- вкладки серверов остаются в шапке удалённой панели, «+» открывает ещё сервер;
- у каждой строки файла есть кнопка «⋮» с тем же меню, что правый клик на
  Windows (сравнить, SHA-256, chmod, zip, поиск, пути);
- панель «Фоновая передача» свёрнута в одну строку и разворачивается кнопкой;
- системная кнопка «Назад» сначала выходит из панелей в список серверов,
  и только оттуда закрывает приложение;
- вход по **4-значному PIN** (мастер-пароль остался на Windows); после 5 ошибок — пауза;
- мультивыбор: долгое нажатие → «Выделить несколько», далее тапы отмечают файлы;
- «Загрузить с телефона» — системный выбор файлов (SAF) с загрузкой в текущую папку;
- ярлыки на иконке: три последних сервера; передачи идут в foreground-сервисе;
- список папок кешируется, повторный вход рисуется мгновенно.

## Синхронизация с телефоном (без аккаунтов)

Настройки → «Синхронизация»:

1. На компьютере: при желании включите «передавать пароли», нажмите
   «Показать QR для телефона» — появится QR и одноразовая ссылка
   `http://<ip>:<port>/sync?token=…`, живущая 5 минут.
2. На телефоне: «Сканировать QR» (камера) или вставьте ссылку вручную.
3. Телефон скачивает JSON по локальной сети и импортирует серверы, группы,
   настройки и (если разрешено) пароли. Дубликаты по `host+port+user`
   пропускаются, группы сопоставляются по имени.

Ограничения: Windows спросит разрешение брандмауэра для приложения — нужно
разрешить для частных сетей; пароли при включённой опции идут по Wi-Fi
открытым текстом (ссылка одноразовая и действует 5 минут).

## Структура

```
rust/core/src/
  api.rs        FFI-поверхность для Dart (единственное, что видит UI)
  model.rs      сериализуемая модель (Server, Entry, Settings, темы, состояние)
  fs/           LocalFs, SftpFs; в P1 добавится ArchiveFs
  ssh/          подключение, TOFU-проверка ключа хоста, exec-канал
  task/         потоковое копирование между провайдерами
  store/        атомарное JSON-хранилище, пути, миграции
  crypto/       Argon2id -> AES-256-GCM, DPAPI-обёртка ключа
app/lib/
  design/       токены, тема, базовые виджеты
  features/     vault, connections, browser
  bridge/       сгенерированный код (не редактировать)
```

## Проверки

```powershell
cargo test -p nova_core                      # 81 unit-тест (крипто, пути, архивы, хранилище, FTPS, diff)
cargo run --example smoke -p nova_core       # сквозной сценарий FFI: хранилище, пароли, DPAPI, сессии
cargo run --example sftp_e2e -p nova_core    # реальный SFTP: встроенный sshd + клиент, upload/download/rename/remove
cargo run --example ftps_check -p nova_core  # реальный FTPS: plain, explicit и implicit TLS + скачивание
cargo run --example compare_check -p nova_core # сравнение файлов: построчный diff + подсветка по словам
flutter analyze && (cd app; flutter test)    # 42 теста UI-хелперов, анализатор без замечаний
```

Последний прогон: все пункты зелёные. SFTP проверен против встроенного в пример сервера
(аутентификация, ключ хоста TOFU, листинг, загрузка, скачивание, рекурсивное удаление,
потоковое копирование SFTP -> локально, обработка ошибок).

## Что уже работает (P0)

- Мастер-пароль: создание/разблокировка хранилища, «запомнить на устройстве» (DPAPI на Windows).
- Список серверов: группы, поиск, добавление/правка/дублирование/удаление.
- Подключение по паролю и по ключу (незашифрованный OpenSSH), TOFU-фингерпринт.
  Окно прогресса показывает этапы и позволяет отменить попытку: сокет закрывается,
  сессия не попадает в список.
- Две панели: локальные диски (список томов, свободное место) и SFTP.
- Навигация: двойной клик, Backspace, path bar по двойному клику, фильтр.
- Файловые операции: копирование (F5), переименование (F2), новая папка (F7), удаление (F8).
- Просмотр файлов (F3) с сервера и локально, потоково, до 256 КБ.
- Сравнение файлов (Ctrl+F3): две панели с подсветкой строк и слов, любые источники
  (локально, SFTP/FTP/S3, архив), в том числе два файла из одной панели.
- Быстрый терминал: выполнение команд в текущей SFTP-сессии.
- Память сессии: последняя папка сервера и локальная панель, восстановление с откатом
  к ближайшей существующей папке.
- Подсветка файлов по маске/регулярке (`*.php` -> красный).
- Полупрозрачное окно Windows (Mica), своя шапка, тёмная тема Nova Graphite.

## Дальше по плану

P1 — архивы: готово (все форматы, упаковка и распаковка на сервере, кеш индекса);
просмотр архива, лежащего **на сервере**, пока идёт через скачивание или
распаковку на сервере — прямое чтение по SFTP в планах.
P2 — темы и редактор тем, встроенный xterm, PuTTY, профили клавиш, сравнение панелей,
P3 — Android-паритет (SAF, Keystore, foreground-передачи, Termux), P4 — полировка.

## Производительность

- Debug-сборка Flutter в разы медленнее release — «тормозит» в `flutter run` это норма.
  Проверять только `tools
un-release.ps1`.
- Impeller на Windows отключён в раннере (`ImpellerSwitch::Disabled`): он идёт через
  ANGLE/GLES и на плотных списках заметно медленнее Skia/D3D.
- Панели больше не обрезаются `Clip.antiAlias` и не анимируются через
  `AnimatedContainer` — это заставляло композитор пересобирать слои каждый кадр.
- `statvfs` (свободное место на сервере) кэшируется на 10 секунд: одна сетевая
  операция вместо одной на каждую навигацию.
- Кадры медленнее 20 мс пишутся в `logs/nova.log` строками `PERF frames=... avg=... p95=...`.

## Проверка UI без реального сервера

```powershell
powershell -ExecutionPolicy Bypass -File tools\ui-demo.ps1
```

Скрипт создаёт временный профиль (`%TEMP%\nova-demo`), поднимает встроенный SFTP-сервер
на `127.0.0.1:2224` и открывает браузер сразу на `/var/www`. В debug-сборке экран
подключений понимает `NOVA_AUTOCONNECT=<id|имя сервера>`; в release переменная игнорируется.

## Если при запуске всплывает «Получите приложение… ms-gamingoverlay»

Это Xbox Game Bar: сам пакет Game Bar из системы удалён, но `GameDVR_Enabled` остался
включён, и Windows пытается открыть отсутствующий оверлей. Лечится на уровне пользователя
(без прав администратора, обратимо):

```powershell
New-ItemProperty 'HKCU:\System\GameConfigStore' -Name GameDVR_Enabled -Value 0 -PropertyType DWord -Force
New-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\GameDVR' -Name AppCaptureEnabled -Value 0 -PropertyType DWord -Force
New-ItemProperty 'HKCU:\Software\Microsoft\GameBar' -Name AutoGameModeEnabled -Value 0 -PropertyType DWord -Force
```

## Требования к окружению

- Rust 1.90+ (проверено на 1.99), Flutter 3.47+, Android SDK с NDK (проверено на 28.2),

- `cargo-ndk` и `flutter_rust_bridge_codegen` (`cargo binstall`).
