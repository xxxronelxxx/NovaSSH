# NovaSSH — Windows UI (Tauri 2 + Svelte)

Десктопный фронтенд для Windows. Ядро общее: `../rust/core` (`nova_core`).
Android по-прежнему собирается из `../app` (Flutter) — тот же профиль и то же
шифрованное хранилище.

## Возможности

- Двухпанельный файловый менеджер: локальные диски и SFTP/FTP/FTPS/S3.
- Все операции WinSCP: F2/F3/F4/F5/F7/F8, Ctrl+F3 (сравнение), Ctrl+F5
  (распаковка), Del, Ctrl+A, Tab, стрелки, Space, быстрый поиск по имени.
- Мультивыделение, сортировка по колонкам, подсветка файлов по правилам,
  перетаскивание между панелями и из Проводника.
- Очередь передач: ограничение скорости, докачка, проверка SHA-256,
  политика конфликтов (спросить/перезаписать/пропустить/переименовать).
- Архивы: открытие локальных и серверных архивов, упаковка и распаковка
  на сервере, пароли, многотомные архивы, добавление файлов в архив.
- Сравнение файлов с подсветкой слов и синхронизация каталогов.
- Встроенный терминал xterm.js, внешний терминал (PuTTY/WT) и внешний
  редактор с авто-загрузкой изменений; ИИ-помощник и сниппеты.
- Журнал редактирования, просмотр логов, импорт WinSCP.ini, правила
  подсветки файлов, QR-синхронизация профиля с телефоном.
- Восстановление прошлой сессии, проверка доступности серверов, группы
  с перетаскиванием, S3/MinIO, блокировка хранилища.

## Разработка

```powershell
cd desktop
npm install
npm run tauri dev
```

В dev-режиме профиль создаётся рядом с `src-tauri/target/debug/nova-desktop.exe`.
Чтобы открыть существующий профиль (серверы и хранилище), задайте переменную:

```powershell
$env:NOVA_DATA_DIR = "D:\work\SSH\dist\NovaSSH\profile"
npm run tauri dev
```

## Сборка

```powershell
npm run tauri build
```

Готовый exe: `src-tauri/target/release/nova-desktop.exe` (переименовывается в
NovaSSH при упаковке). Профиль лежит в `profile\` рядом с exe, как у портативной
Windows-версии.
