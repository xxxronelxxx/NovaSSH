NovaSSH {VERSION} — Windows x64, portable
=========================================

Запуск
------
NovaSSH.exe

Все данные хранятся в папке profile рядом с программой:
  profile\servers.json    серверы и группы (без паролей)
  profile\secrets.json    пароли и ключи (зашифрованы DPAPI)
  profile\settings.json   настройки
  profile\snippets.json   сниппеты команд
  profile\logs\           журналы
  profile\tmp\            временные копии редактируемых файлов

Мастер-пароль на Windows не нужен: хранилище открывается ключом этого
компьютера. Папку profile можно перенести вместе с программой на другой
компьютер, но сохранённые пароли там будут недоступны — их нужно ввести заново.

Портативный режим
-----------------
Если запускать из папки, куда нет прав записи, задайте переменную окружения
NOVA_DATA_DIR на свою папку данных.

Удаление
--------
Программа не устанавливается: просто удалите папку. Перед удалением сохраните
profile, если он нужен.
