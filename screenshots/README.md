# Скриншоты Nova SSH

Все снимки сделаны в изолированном демо-профиле на локальных тестовых серверах
(`127.0.0.1`, пользователь `demo`), без реальных серверов и данных.

- `01-servers.png` — список серверов и группы. Светлая тема.
- `02-file-manager.png` — двухпанельный режим: локальный проект и `/demo` на SFTP.
- `03-editor.png` — встроенный редактор с подсветкой PHP.
- `04-settings-snippets.png` — настройки, вкладка «Сниппеты».
- `05-terminal.png` — терминал с лентой избранных сниппетов.
- `06-file-manager-dark.png` — тот же файловый менеджер в тёмной теме.

Размер: 1475×950, PNG с оптимизацией. Для сайта можно показывать как есть или
уменьшить до ширины 1200–1400 px.
